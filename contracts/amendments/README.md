# ScopeKeeper Official SOW Amendments Directory

This directory stores legally binding Statement of Work (SOW) amendments generated autonomously by ScopeKeeper when Change Orders are authorized by clients via Telegram (`@AcmeClientDesk_bot`) or the ScopeKeeper Client Portal.

Each amendment references the governing Statement of Work (SOW v1.2), details the approved scope deliverable, commercial terms, implementation artifacts, and digital audit digests.
