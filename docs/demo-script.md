# ScopeKeeper — 3-Minute Demo Script

This script walks through the **ten demonstration beats** of ScopeKeeper for the **Flip the Switch Hackathon (Track 1: Best Business Workflow)**.

**Screen Setup:**
- **Left:** Discord (`Acme Inc.` client server, channel `#acme-client`, Sam active).
- **Right:** Slack (`Pixel & Co` agency workspace, channels `#acme-intake`, `#acme-delivery`, `#acme-cr-004`, Priya and Ravi active).
- **Top / Split:** ScopeKeeper Web Dashboard (`http://localhost:5173`) showing dual clocks (`Asia/Kolkata` and `America/New_York`), `@client-desk` holder, and live SSE event stream.
